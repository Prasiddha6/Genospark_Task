# Validation Checklist

Run validation against the intended staging database.

- Verify provider IDs.
- Check category and service counts.
- Check for duplicate canonical services.
- Confirm every intended service has challenge records.
- Confirm levels are within 1–10.
- Confirm each options JSON value is valid.
- Confirm each challenge has four options and exactly one correct answer.
- Check SVG mappings against verified asset filenames.
- Record actual query results after running the checks.

Do not mark a check complete until it has been run and verified.
